# Ancla Web

Sitio web de Ancla Web: páginas web y sistemas para negocios.

Página estática (HTML, CSS y JavaScript en un solo `index.html`) publicada con GitHub Pages.
Las capturas de los proyectos están en `img/`.

## Demos para clientes

- `demos/galvanotecnia/` — propuesta para cliente de equipos de galvanotecnia. Datos editables en el objeto `CONFIG` al final del archivo.
